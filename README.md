# opencode-config

Personal OpenCode config (`~/.config/opencode`).

- `opencode.json` / `cli.json` - OpenCode settings
- `oh-my-opencode-slim.json` - plugin presets (`gc-*` = claude-agent + opencode-go, `p-*` = github-copilot)

`service.json` holds a local password and is intentionally not tracked; recreate it on a new machine.
